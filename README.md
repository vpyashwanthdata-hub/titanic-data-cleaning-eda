# 🚢 Titanic Data Cleaning and Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on performing **Data Cleaning** and **Exploratory Data Analysis (EDA)** on the Titanic dataset. The objective is to improve data quality by handling missing values, removing inconsistencies, and exploring relationships between variables to identify meaningful patterns and trends.

This project was completed as part of the **System Tron – Generative AI Internship (Week 2)**.

---

## 🎯 Objectives

- Clean and preprocess the Titanic dataset.
- Identify and handle missing values.
- Detect inconsistencies and duplicate records.
- Perform Exploratory Data Analysis (EDA).
- Discover relationships between important variables.
- Summarize key insights and trends.

## 🧹 Data Cleaning

The following preprocessing steps were performed:

- ✔ Checked for missing values
- ✔ Handled missing data using appropriate imputation techniques
- ✔ Removed duplicate records (if present)
- ✔ Corrected inconsistent data
- ✔ Verified data types
- ✔ Prepared the dataset for analysis

---

## 📊 Exploratory Data Analysis (EDA)

EDA was conducted to understand the dataset and identify meaningful patterns.

The analysis included:

- Distribution of passengers
- Survival analysis
- Age distribution
- Gender-wise survival
- Passenger class analysis
- Missing value analysis
- Relationship between passenger class and survival
- Relationship between age and survival

---

## 🔍 Key Insights

Some important observations include:

- Female passengers had a higher survival rate than male passengers.
- First-class passengers showed higher survival rates compared to lower classes.
- Missing values were mainly found in the Age and Cabin columns.
- Passenger class had a strong influence on survival.
- Data cleaning significantly improved the quality of the dataset for analysis.
